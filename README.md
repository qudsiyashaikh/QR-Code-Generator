# 📷  QR Code Generator

A fast, lightweight, and modern web application built with Python and Flask that instantly converts any text inputs or website URLs into functional, high-quality **QR Codes**.

## 🚀 Key Features
* **Text & URL Encoding:** Seamlessly transforms URLs, paragraphs, or credentials into a scannable matrix.
* **In-Memory Rendering:** Generates and renders QR codes dynamically on the browser via Base64 encoding without saving bulky image files on the server storage.
* **Clean Layout:** Minimalistic and fully responsive user interface.

## 🧠 Concepts Covered & Learning Journey

This project was developed independently to strengthen my knowledge of handling media streams and third-party libraries within web frameworks. To ensure cross-platform compatibility and fix installation warnings, I actively integrated structured documentation from **Google searches** and engaged with **AI tools (Gemini/ChatGPT)** for architectural optimization.

Key backend concepts used include:
* **Advanced Python Library Use:** Utilizing `qrcode` along with `Pillow (PIL)` to handle background pixel manipulation.
* **Data Streams & I/O Operations:** Leveraging `io.BytesIO` to write binary image outputs directly into data buffers.
* **Base64 String Encoding:** Converting raw image byte arrays into `ASCII` text strings to embed them inside live HTML tags.

---

## 🛠️ Tech Stack Used

* **Backend:** Python 3.x, Flask Web Framework
* **Libraries:** `qrcode`, `Pillow` (PIL wrapper)
* **Frontend:** Semantic HTML5, Embedded CSS3 styling
